Logic is a valid system of formal reasoning, it uses symbols according to syntax and applies the rule of interference to avoid any un intended prejudices entering the reasoning process

Proposition is something that can only be true or false 
A boolean is literally the definiton of true or false

A proposition that relies on other propositions is a compound proposition 

We can use symbols for propositions whose value we don't know yet like p,q,r,s

The three most important logical operators are AND, OR and
NOT

">" = Greater than , "<" = Less than

"$\wedge$" (AND / Conjunction): Denoted by a 'wedge' symbol, <mark>this operator combines two propositions and evaluates to true only if both individual components are true</mark>. For instance, $p \wedge q$ means the cursor's x-coordinate is simultaneously greater than $x1$ and less than $x2$. 

"$\vee$" (OR / Disjunction): Denoted by a 'vee' symbol, <mark>this evaluates to true if either component is true, or if both are true</mark>.
